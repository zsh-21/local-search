# LocalSearch - 极简本地文件 & 应用搜索工具

LocalSearch 是一款基于 **Electron + React + Vite** 开发的轻量级 Windows 桌面搜索工具。它旨在提供类似 macOS Spotlight 或 Listary 的流畅体验，通过全盘索引实现秒级的文件和应用查找。

## ✨ 功能特性

- 🚀 **秒级搜索**：后台自动建立本地文件索引，支持几十万量级文件秒级模糊匹配。
- ⌨️ **全局唤起**：通过 `Alt + S`（或 `Ctrl + Alt + S`）随时随地唤起搜索框，无需干扰当前工作流。
- 🖱️ **自由移动**：窗口顶部设有隐藏把手，支持鼠标抓取拖拽（Grab），自由放置在屏幕任何位置。
- ⚡ **虚拟列表优化**：采用虚拟滚动技术（Virtual Scroll），即使搜索结果成千上万条，界面依然丝滑不卡顿。
- 📂 **快捷操作**：
  - **回车**：直接打开文件或启动应用。
  - **目录按钮**：一键打开文件所在的文件夹并自动选中。
  - **复制按钮**：快速复制文件的完整路径。
- 🎨 **现代 UI**：精致的深色模式设计，支持搜索状态 Loading 动画及索引构建提示。

## 🛠️ 技术栈

- **前端**: React 18, TypeScript, CSS3
- **后端 (主进程)**: Electron 29, Node.js
- **构建工具**: Vite 5
- **核心库**: `react-window` (虚拟滚动), `electron-builder` (打包)

## 🚀 快速上手

### 1. 克隆与安装

```bash
# 安装依赖
npm install
```

### 2. 开发模式

```bash
npm run dev
```

### 3. 构建打包 (生成安装包)

```bash
npm run build
```
打包产物将位于 `release/1.0.0/` 目录下。

## ⌨️ 快捷键指南

| 快捷键 | 功能 |
| :--- | :--- |
| **Alt + S** | 唤起 / 隐藏搜索框 (主快捷键) |
| **Ctrl + Alt + S** | 备用唤起快捷键 (当主键被占用时) |
| **↑ / ↓** | 在搜索结果中切换选择 |
| **Enter** | 打开选中的文件或应用 |
| **Esc** | 隐藏搜索窗口 |

## 📝 索引说明

- 首次启动时，程序会自动扫描本机所有盘符建立索引。
- 索引文件加密存储在系统的 `userData` 目录中。
- 如需重新扫描，可通过托盘菜单或相关 IPC 命令触发。
